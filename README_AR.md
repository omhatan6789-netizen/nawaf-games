# بوت نواف — Node.js

مشروع موحّد للبوت وميني آب والألعاب على خادم Render واحد.

## التشغيل محليًا
1. ثبّت Node.js 22 أو أحدث.
2. انسخ `.env.example` إلى `.env` وأضف BOT_TOKEN وDATABASE_URL.
3. نفّذ `npm install` ثم `npm start`.

## المسارات
- `/health` فحص صحة الخادم.
- `/miniapp` واجهة الميني آب.
- `/api/health/db` فحص اتصال قاعدة البيانات.

هذا هيكل تأسيسي فقط؛ نقل أوامر البوت والألعاب يتم تدريجيًا مع اختبار كل جزء قبل إيقاف النسخة القديمة.
